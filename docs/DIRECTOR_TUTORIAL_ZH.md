# 漫剧导演新手制片实战教程 (Director's Manual)

欢迎使用 **Mannequin Director（漫剧虚拟制片与导演运镜系统）**！

本模组专为 **AIGC 漫剧创作者、动画短片创作者与影视分镜导演** 设计。你无需学习 Blender、Maya 或虚幻引擎复杂的骨骼绑定与关键帧时间线；在 Minecraft 中，你可以像在真实片场一样：
> **“自己化身演员，把角色一个一个演出来；再化身摄影师，飞着穿越机把它拍下来！”**

## 🚀 5 分钟上手实操演练

假设我们要拍摄一个镜头：**“红衣主角在街巷中狂奔闪避，汽车呼啸而过，穿越机贴地俯冲跟拍”**（时长 6 秒）。

```
┌─────────────────────────────────────────────────────────────┐
│ 步骤 1: 布景与染色 ──► 放置人偶，拿红染料右键变成纯红替身   │
│ 步骤 2: 附身动捕 ────► 瞄准红人按 [G] 附身，按 [K] 录制跑动 │
│ 步骤 3: 倒带复位 ────► 按 [R] 键，红人瞬间瞬移回起点第 0 秒 │
│ 步骤 4: 录制第 2 轨 ──► 附身汽车开过，红人在旁边幽灵伴跑！   │
│ 步骤 5: 穿越机实拍 ──► 按 [F6] 飞起，[V]开竖屏，[F1]纯净录制│
└─────────────────────────────────────────────────────────────┘
```

### 第一步：场景搭建与角色染色
1. 手持 **“漫剧人偶”** 道具，在场景起点右键地面放置一个人偶；
2. 手持原版 **红色染料** 右键人偶，人偶变为 **纯红高饱和度替身**（代表主角 A）；
3. 拿着 **蓝色染料** 在旁边放第二个人偶并染色（代表反派 B 或载具）。

### 第二步：第一轨动捕（录制红衣主角跑动）
1. 准星对准红人偶，按下键盘 **`G`** 键，视角瞬间切入红人偶的第一人称（附身完成）；
2. 此时屏幕右上角显示新手引导，底部提示 **“已处于附身操纵状态”**；
3. 按一下 **`K`** 键，片场时间轴启动（00.0s $\to$ 06.0s），动捕录制开始！
4. 你直接用键盘 **WASD** 操纵红人偶往前狂奔，在第 3 秒时向右急转弯假装闪避；
5. 到达 6 秒时系统自动停止录制，或中途按 `K` 结束。

### 第三步：一键倒带复位（Rewind）
* 按一下键盘 **`R`** 键。
* **奇迹时刻**：全场所有人偶瞬间吸回第 0 秒的初始站桩点，姿态和位置完全归位！

### 第四步：第二轨叠录与“幽灵伴跑”（录制汽车/对手）
1. 准星对准第二个实体，按 **`G`** 键附身；
2. 按 **`K`** 键开启录制！
3. **核心黑科技（幽灵伴跑）**：此时刚才录好的红人偶在旁边**完全自动播放跑动和闪避**！
4. 你操纵第二个实体从他身边呼啸擦过，完美配合他的闪避节奏；
5. 跑完按 **`R`** 键再次倒带复位。

### 第五步：FPV 穿越机实拍运镜
1. 按 **`F6`** 键进入导演自由相机，按 **`V`** 键切换为 **`9:16 竖屏漫剧`** 遮罩（两侧黑边自动贴合，出现黄金构图三分线）；
2. 按 **`Space`（空格键）**，全场演员和车辆同步开跑！
3. 你推着鼠标操纵穿越机，在他们身边贴地穿梭俯冲（鼠标急转弯镜头会自动帅气侧倾 30°）；
4. 按原版 **`F1`** 键一键隐去所有文字和辅助线，打开 OBS 录屏，一条好莱坞级的运镜生肉素材即刻出炉！

## 🎮 导演快捷键速查表

> 💡 **提示**：游戏内随时可按 **`H`** 键展开/折叠右上角的极简指引卡片。所有按键可在原版「选项 $\to$ 控制 $\to$ 按键绑定 $\to$ 漫剧导演与虚拟制片」中自定义。

| 快捷键 | 默认按键 | 功能用途 |
| :---: | :---: | :--- |
| **开启/退出导演相机** | **`F6`** | 切入脱离本体的 FPV 穿越机飞控视角 |
| **附身/脱离实体** | **`G`** | 准星瞄准人偶/载具一键附身，操控跑位 |
| **动捕录制开关** | **`K`** | 附身后开始/停止逐帧记录角色移动路线 |
| **排演播放/暂停** | **`Enter`** / **`Space`** | 全场所有轨道同步起跑，排练整体节奏 |
| **一键倒带复位** | **`R`** | 全场角色与相机瞬间瞬移回第 0 秒初始机位 |
| **切换画幅遮罩** | **`V`** | 循环切换：全屏 $\to$ 9:16竖屏 $\to$ 16:9宽屏 $\to$ 21:9宽银幕 |
| **折叠/展开引导卡** | **`H`** | 隐藏或显示右上角新手 3 步制片指引卡片 |
| **镜头手动滚转** | **`Z`** / **`X`** | 镜头向左/向右倾斜（Dutch Angle 动漫张力构图） |
| **场景时长加减** | **`]`** / **`[`** | 场景总录制时间增加/减少 1 秒（默认 6 秒） |
| **纯净录制模式** | **`F1`** | 原版隐藏 HUD，自动隐藏所有辅助线输出纯净视频 |

## 🤖 AIGC 下游工作流衔接（Kling / Wan2.1 / ComfyUI）

录制好的纯色替身视频，如何送入视频生成大模型？

### 1. 自然语言提示词（Prompt）绑定逻辑
多模态视频大模型（如 Kling 1.5/2.0、Wan2.1、Gen-3）的 Cross-Attention 机制对单色对比极度敏感：

```text
[提示词模板]
A cinematic anime scene, high dynamic camera movement, rainy cyberpunk street.
The pure red figure represents a young male detective with messy silver hair in a black leather coat, sprinting and dodging.
The pure blue vehicle represents a futuristic neon hover-bike speeding past him.
8k, master lighting, photorealistic anime style.
```

### 2. ComfyUI 局部重绘与遮罩提取（Color Mask / Chroma Key）
因为我们的模型是纯色且支持无光照纯平自发光模式（Unlit）：
1. 在 ComfyUI 中接入 **`Mask by Color`** 或 **`Color Key`** 节点；
2. 吸管直接吸取人偶的纯红色（`#FF0000`），1 秒内提纯出完美的单人 Alpha 蒙版；
3. 将蒙版连接至 ControlNet / Inpaint 局部重绘单元，分别对角色 A 和角色 B 输入独立的提示词与 LoRA，**彻底根治多人物串色、脸部衣服互融的世界级难题**！

## ❓ 常见问题排查（FAQ）

* **Q：为什么准星对准人偶按 `G` 附身没反应？**
  * 答：请确保距离人偶在 10 格以内，且准星中心正对人偶身体。
* **Q：为什么画面录出来有很多网格线和文字？**
  * 答：拍摄前按键盘 **`F1`** 键，模组会自动保留黑边遮罩并隐去所有三分线和状态文字。
* **Q：场景时长 6 秒不够用怎么办？**
  * 答：按键盘的 **`]`** 键，每按一次增加 1 秒（如 7s、8s、10s）。
