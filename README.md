## 📖 简介 / Introduction

**Anime Director（漫剧导演）** 专为 **AIGC 漫剧创作者、动漫短视频团队、动画导演与影视分镜师** 设计。

无需掌握 Blender / Maya 复杂的骨骼绑定、蒙皮权重与关键帧曲线调试。在 Minecraft 沙盒世界中，你可以像在真实好莱坞虚拟影棚中一样：
> **“自己化身演员，把角色一个一个演出来；再化身摄影师，飞着穿越机把它拍下来；最后直接生成标准 MP4 视频喂给 AI 大模型！”**

录制输出的高对比度纯色替身（Stand-in Proxy）视频，可无缝送入 **可灵 (Kling)、Wan2.1、Runway Gen-3、Seed-Story、ComfyUI** 进行重绘与风格化渲染，彻底根治多角色同框串色、肢体穿模混乱与运镜呆板的世界级难题。

## ✨ 核心特性模块 / Key Features

### 1. 🎭 替身演员系统 (Stand-in Proxy Mannequins)
- **极简几何圆柱替身**：专为 AIGC 空间语义理解优化，纯净无噪点，自带顶部视向箭头，分清角色正反面。
- **纯色角色语义绑定**：手持原版染料右键直接染色（纯红/纯蓝/纯绿等），完美适配 ComfyUI 色度键（Chroma Key）吸管抠像。
- **Unlit 纯平无光影模式**：手持火把或荧石粉右键人偶，一键开启纯平自发光，不受任何阴影与方块漫反射干扰。
- **5% ~ 2000% 无级自由缩放**：准星对准人偶按住 `Shift + 滚轮`，无级缩放体型（从手办微缩到百米摩天巨像），内置**目标吸附锁定**与**快捷栏防误切保护**。

### 2. 🪄 导演工杖套件 (Director's Wand Suite)
- **漫剧导演工杖 (Director's Wand)**：
  - 右键地面：放置 100% 标准立式圆柱替身；
  - 右键人偶：单体精准回收并抹除时间轴对应轨迹（生存模式返还工杖）；
  - `Shift + 右键地面/空气`：16 格大范围一键批量清场并抹除轨迹。
- **卧式导演工杖 (Lying Director's Wand)**：
  - 右键地面：直接放置水平平躺圆柱替身（专为倒地、入睡、重伤、被击飞等场景打造）；
  - 同样拥有完整的一键回收、体型缩放与批量清场能力。

### 3. 🎬 提线木偶动捕与时间轴系统 (Puppetry MoCap & Timeline)
- **附身操控 (`G` 键)**：准星瞄准任意人偶按 `G` 立即附身，拥有完整的本地客户端物理操纵权威，走位顺滑无卡顿。
- **逐帧录制 (`K` 键)**：附身状态下按 `K` 开启录制，按 WASD 操纵演员跑位、跳跃、移动。
- **多轨叠录与幽灵伴跑 (Ghost Replay)**：录制下一条角色轨道时，已录制的所有其他角色会自动在身旁同步跑位配合。
- **一键倒带复位 (`R` 键)**：按 `R` 键，全场所有演员与机位瞬间瞬移回第 0 秒起点，零成本无限次重排重演。

### 4. 🎥 FPV 航模穿越机与分镜机位系统 (FPV Camera & Stations)
- **自由飞控视角 (`F6` 键)**：脱离本体自由飞行，带惯性阻尼滑行与地面高度贴地感。
- **双运镜动力学 (`F9` 键切换)**：
  - *平稳防抖模式*：水平推拉摇移，适合对话分镜与大景深巡航；
  - *FPV 航模模式*：转弯沿切向自动侧倾（Dutch angle），适合极速追车与跑酷俯冲打斗。
- **分镜拍摄机位站 (`B` 键)**：在场景中打下多个固定拍摄机位（全景站、特写站、跟拍站），支持多机位批处理自动巡游录制。
- **多档位巡航航速 (`J` 键)**：慢速细腻推拉 (0.3x) $\to$ 标准速度 (1.0x) $\to$ 极速航模 (2.5x) $\to$ 超音速 (5.0x)。

### 5. 📐 画幅遮罩与实拍录像 (Aspect Ratio & Live MP4)
- **多规格专业画幅 (`V` 键)**：循环切换 `全屏` $\to$ `9:16 竖屏漫剧 (抖音/快手/小红书/Shorts)` $\to$ `16:9 院线影视` $\to$ `21:9 宽银幕`，带三分黄金分割参考线。
- **主视角实时 MP4 录制 (`F10` 键)**：一键启动/停止实时运镜录像，与 20 TPS 逻辑帧严格 1:1 同步，拒绝变速快放，无损输出标准 MP4 文件。

### 6. 🏗️ 片场建筑蓝图仪 (Studio Build Wand)
- **选区框定**：手持蓝图仪，左键方块设定点 A，右键方块设定点 B（绿色立体边框，线宽 3.0，自动防误触）。
- **一键打包**：选区就绪后按 `Enter` 键直接导出为 `.director_blueprint` 蓝图文件。
- **全息放置与秒建**：全息投影预览建筑结构，滚轮旋转 90°，`Shift + 滚轮` 微调高度；右键地面瞬间自动施工落成（生存模式自动消耗背包材料）。
- **清空选区**：按 `Delete` 键单键清除未闭合选区。

### 7. 🎵 片场曲库与实训手册 (Studio Music & Guidebook)
- **片场配乐引擎 (`M` 键 / 快捷中心)**：支持片场背景音乐播放、切歌、洗牌随机与循环模式，优化原生堆外内存回收。
- **交互实训手册 (`H` 键)**：内置从零到一的沉浸式实训教程，带章节式步骤指引与热键对照。
- **导演快捷中心 (`C` 键)**：一键呼出沉浸式快捷轮盘面板，聚合所有核心操控。

## 🚀 5 分钟上手实操演练

假设我们要拍摄一个镜头：**“红衣主角在街巷狂奔，蓝色对手从后方追赶，穿越机贴地俯冲跟拍”**（时长 6 秒）。

```
┌────────────────────────────────────────────────────────────────────────┐
│ 步骤 1: 摆放替身 ──► 手持【漫剧导演工杖】右键地面放置红人与蓝人         │
│ 步骤 2: 纯色染色 ──► 拿红/蓝染料右键人偶，指定角色语义纯色 (主角A/对手B)│
│ 步骤 3: 附身动捕 ──► 准星瞄准红人按 [G] 附身，按 [K] 录制主角狂奔跑位  │
│ 步骤 4: 倒带复位 ──► 按 [R] 键，红人瞬间归位回第 0 秒起点站桩点         │
│ 步骤 5: 录制第 2 轨 ► 附身蓝人按 [K]，红人在前方自动幽灵伴跑配合对手戏！│
│ 步骤 6: 运镜与实拍 ─► 按 [F6] 升起穿越机，按 [V] 切 9:16 竖屏，[F10] 录制│
└────────────────────────────────────────────────────────────────────────┘
```

## 🤖 AIGC 下游工作流衔接 (Kling / Wan2.1 / ComfyUI)

### 1. 提示词（Prompt）绑定逻辑
多模态视频大模型的 Cross-Attention 对强对比纯色块极为敏锐：
```text
A cinematic anime action sequence, high dynamic camera movement, rainy cyberpunk alley.
The pure red cylinder stands for a teenage male detective with messy white hair sprinting forward.
The pure blue cylinder stands for a sleek heavy armored enforcer chasing him with a blade.
Master anime aesthetic, Ufotable style lighting, 8k, fluid motion blur.
```

### 2. ComfyUI 局部重绘与遮罩提取（Color Mask / Chroma Key）
1. 在 ComfyUI 中接入 **`Mask by Color`** 或 **`Color Key`** 节点；
2. 吸管直接吸取人偶的纯红色（`#FF0000`）或纯蓝色（`#0000FF`），即可秒级提纯出完美的单人 Alpha 蒙版；
3. 将蒙版连接至 ControlNet / Inpaint 局部重绘单元，分别对角色 A 和角色 B 输入独立的提示词与 LoRA；
4. **彻底解决多人物同框时发色互相污染、衣服融合的世界级难题**！

## 🛠️ 构建与开发 (Build & Development)

### 开发环境要求
- **Java**: 21 (推荐 Eclipse Temurin / GraalVM)
- **Minecraft**: 1.21.1
- **Mod Loader**: NeoForge 21.1.251+
- **构建工具**: Gradle 8.10+ (内嵌 Wrapper)

### 本地编译命令
```bash
# 1. 克隆代码仓库
git clone https://github.com/aishangwuji/anime_director.git
cd anime_director

# 2. 执行全量单元测试 (自动化校验时间轴、数学插值与实体逻辑)
./gradlew test --no-daemon

# 3. 编译打包生产 Jar
./gradlew build -x test --no-daemon

# 构建产物位于: build/libs/anime_director-0.1.0.jar
```
